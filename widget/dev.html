Clínica Dental Sonrisa — sitio de prueba

Esta página simula el sitio de un cliente de Hablia. El widget flotante de abajo debe abrir un chat y responder con la base de conocimientos (horarios, dirección).

Pruebas: pregunta «¿qué horarios tienen?», luego algo desconocido («¿venden planes odontológicos?»), y «quiero hablar con un humano».
